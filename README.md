## 付款之后：先确认实例真的能用

实例付款后会自动启动，不需要手动开机，状态依次经过待启动、启动中，最后进入运行中。

有个细节要留意：运行中不代表马上能远程连接。Running状态只说明实例本身在运行，要等操作系统启动完成、网络服务正常工作后，才能通过SSH（Linux）或RDP（Windows）远程登录。控制台里可以查看实例健康状态，用它判断系统是否已经运行，连不上时先看这里，比反复重试密码有用。

连上之后建议尽快做两件事。一是给云盘设置快照：云盘有多副本机制，数据可靠性达99.9999999%，但多副本防的是硬件故障，误删的文件还得靠快照找回来。二是核对安全组规则，确认业务需要的端口（比如Web服务常用的80和443）已经放行。

## 新手容易忽略的几个细节

- 按量付费实例配合节省停机模式：停止实例时启用这个模式，会释放vCPU、内存和固定公网IP并停止计费，云盘、弹性公网IP等资源保留并继续收费。测试机长期闲置时，这个开关省的是计算资源的钱。
- 有些操作要先停机：更换操作系统、修改私有IP地址、按量付费实例变配规格，都需要先把实例停到已停止状态再操作。
- 退款前先把数据导出来：包年包月实例退款停机后，vCPU、内存、固定公网IP、快照会在24小时内释放，云盘最长保留15天，实际释放时间还可能提前。买错想退，先备份再操作。
- 用了本地盘要自己做冗余：本地盘只有部分实例规格配备，且只能用作数据盘；云盘有三副本保障，本地盘的数据需要你在应用层自己做冗余。
- 担心误释放就开释放保护：实例释放后，实例ID、固定公网IP、系统盘和设置随实例释放的数据盘不可恢复，独立的EIP和数据盘会自动解绑。重要实例建议启用释放保护。
- 免费的安全能力记得用上：安全组免费；DDoS基础防护默认开启，提供不超过5Gbps的防护能力；基础安全服务免费提供异常登录检测、漏洞扫描和基线配置核查。

## 常见问题

**买完需要手动启动实例吗？**

不需要。通过控制台购买创建后，实例会自动启动，等待状态变为运行中即可。

**地域选错了能改吗？**

不能。实例创建后无法更换地域，只能释放后在新地域重新购买。包年包月实例可以申请退款，注意先备份数据，云盘数据退款后最长只保留15天。

**抢占式实例能长期跑业务吗？**

不适合。它靠竞价获得折扣，代价是存在回收机制，平台可能回收实例，承载不能中断的业务风险太高。

**一台ECS每月到底花多少钱？**

取决于实例规格、存储、公网带宽和快照的用量，没有统一答案。在购买页把配置选好后会显示对应价格，按这个数字做预算即可。

**实例显示运行中，为什么连不上？**

运行中只代表实例在运行，操作系统没启动完就无法远程连接。在控制台查看实例健康状态，等系统运行后再用SSH或RDP登录。
